# 자료구조

| 구조 | 역할 | 시간 | 공간 |
| --- | --- | --- | --- |
| `Node nodes[LIMIT]` | 정점 번호로 장비 슬롯 조회 | 조회 O(1), 빈 슬롯 검색 O(V) | O(V) |
| `Edge` 인접 연결 리스트 | 장비에 연결된 회선만 순회 | 회선 조회 O(deg(u)), 추가·삭제 O(deg(u)+deg(v)) 상한 | O(V+E), 회선마다 두 항목 |
| `Queue` 원형 배열 | BFS가 발견한 정점을 입력 순서로 처리 | 삽입·제거·상태 조회 O(1) | O(V) |
| `Stack` 배열 | 장애와 복구 직전 상태를 저장 | push·peek·pop O(1) | O(H), H=128 |
| 거리·방문·이전 정점 배열 | 탐색과 경로 복원 | 번호로 접근 O(1) | O(V), 단계 복사본 최대 O(V²) |

여기서 V는 장비 슬롯 용량(최대 32), E는 회선 수다. 양쪽 목록에 모두 삽입할 수 있도록 회선 두 항목을 먼저 할당한다. 첫 할당만 성공해도 실패 경로에서 반환한다. 삭제할 때는 각 목록에서 해당 항목을 찾아 연결을 우회하고 `free` 한다. 노드 삭제는 연결 회선을 양쪽에서 모두 제거한다.

회선 비용은 1~10,000의 정수다. 장애는 정점 또는 회선의 활성 상태를 바꾸므로 연결 관계가 보존된다. 장비나 회선을 삭제하면 기존 Undo 기록을 지운다. 한 예제에 여러 장애가 있으면 Undo 한 번은 개별 장애 한 건을 되돌린다.
