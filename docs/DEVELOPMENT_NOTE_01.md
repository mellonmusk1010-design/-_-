# 1차시 개발노트 · 문제 정의와 설계

- 주제 — 장비와 회선이 고장 났을 때 가상 통신망에서 대체 경로 찾기.
- 선정 이유 — 단일 회선이 끊어져도 예비 회선이 있으면 서비스를 계속 제공할 수 있다. 우회에 필요한 비용과 전체 도달 범위를 같은 화면에서 비교하도록 설계했다.
- 사용 대상 — 자료구조를 배우는 학생과 모의 네트워크의 복구 과정을 확인하려는 학습자.
- SDG 9 — 예비 경로가 인프라 복원력에 어떤 영향을 주는지 기존 비용, 우회 비용, 통신 가능 여부로 확인한다.
- SDG 11 — 도시 재난 시나리오에서 가상의 병원과 재난 상황실 사이 통신 유지 여부를 확인한다.
- 자료구조 탐구 — 연결 리스트로 무방향 인접 목록을, 원형 큐로 BFS 순서를, 스택으로 장애 이전 상태를 저장한다. 배열로 방문 여부와 이전 정점을 저장한다. 단계별 기록은 C 엔진이 만든다.
