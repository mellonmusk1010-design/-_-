# 3차시 개발노트 · 검증과 개선

`3b20cf9`에서 Chromium 통합 테스트를 추가했다. 브라우저가 실제 WebAssembly 모듈을 로드한 뒤 다음 동작을 비교한다.

- 학교 네트워크 — 회선 장애로 1층 라우터 경로(비용 6)가 2층 라우터 경로(비용 10)로 바뀌며 비용 변화율 66.7%가 표시된다. Undo로 처음 경로가 돌아온다.
- 도시 재난 통신망 — 주 중계기 장애 후 예비 중계기와 소방서를 경유한다. 장비를 복구하면 주 중계기 경로가 다시 선택된다.
- 완전 단절 — 두 장애를 동시에 적용하면 통신 불가이며 출발지에서는 장비 6대 중 3대에 도달할 수 있다.
- 편집과 시각화 — 장비 드래그, 이름 변경, 회선 비용 변경, 장애·복구, 삭제, BFS 큐, 이전·다음 단계와 재생을 확인했다.

C 자동 테스트와 AddressSanitizer·UndefinedBehaviorSanitizer 검사, TypeScript 검사, Vite 빌드, Chromium 통합 테스트가 통과했다. Windows와 WSL에서의 실행은 별도 검증이 필요하다.

**학생 보완** — 직접 재현한 세 시나리오의 화면을 기록하고, 결과가 달랐다면 선택한 알고리즘과 입력을 함께 적는다.
