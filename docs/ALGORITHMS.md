# 경로 탐색

BFS는 시작점을 큐에 넣은 뒤 먼저 발견한 장비부터 꺼낸다. 처음 발견한 순간 홉 수와 이전 정점을 기록해, 같은 장비가 큐에 중복 삽입되는 일을 막는다. 연결 비용은 경로를 고르는 데 쓰지 않으며 복원한 경로의 실제 비용은 별도로 합산한다.

다익스트라는 확정되지 않은 정점 중 현재 거리 배열에서 값이 가장 작은 정점을 고른다. 연결된 정점까지 새 비용이 더 낮으면 거리와 이전 정점을 갱신한다. 시작점 비용은 0, 미발견 정점은 배열에서 -1이고 화면에서는 ∞다. 양수 비용 덕분에 확정한 정점에 더 싼 경로가 나중에 생기지 않는다.

두 탐색 모두 장애 회선과 장애 장비를 건너뛴다. 목적지를 찾은 뒤에도 출발지에서 도달할 수 있는 장비를 끝까지 센다. 최종 경로는 목적지부터 이전 정점을 따라간 뒤 순서를 뒤집는다. 정상 장비를 출발지와 목적지로 동시에 선택하면 비용과 홉이 0이며 경로에 정점 하나가 들어간다.

| 작업 | 시간 | 추가 공간 |
| --- | --- | --- |
| BFS 탐색 자체 | O(V+E) | O(V) |
| 배열 기반 다익스트라 탐색 자체 | O(V²+E) | O(V) |
| 단계 기록 포함 | 탐색 시간에 O(V²) 추가 | O(V²) |

직접 연결 비용 20, 중간 장비 두 대를 거치는 각 비용 2의 예제에서 BFS는 한 홉 비용 20을, 다익스트라는 세 홉 비용 6을 선택한다. 이 차이는 `engine/tests/test_net.c`에서 검증한다.
