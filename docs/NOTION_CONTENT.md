# NetRecover · 네트워크 장애 복구 시뮬레이터

장비나 회선에 장애가 발생해도 출발지에서 목적지까지 통신할 수 있는지 모의 실험한다. BFS는 최소 홉 경로를, 다익스트라는 최소 비용 경로를 찾는다. C 엔진이 저장한 탐색 단계의 큐, 거리와 이전 정점을 웹에서 재생할 수 있다.

## 1차시 · 주제와 설계

장비를 정점으로, 회선을 양수 비용이 붙은 무방향 간선으로 모델링했다. 장애 상태를 별도로 관리해 복구 시 같은 회선을 다시 쓸 수 있다. SDG 9의 인프라 복원력과 SDG 11의 재난 통신 유지에 연결한 프로젝트다. [개발노트 1](DEVELOPMENT_NOTE_01.md)

## 2차시 · 엔진과 웹 구현

인접 연결 리스트, 원형 큐, Undo 스택을 C17로 구현했다. `search`가 방문 정점을 결정하고 `step_value`가 그 기록을 웹에 전달한다. 경로는 이전 정점 배열을 역추적해 복원한다. [개발노트 2](DEVELOPMENT_NOTE_02.md)

## 3차시 · 시나리오 검증

학교는 회선 장애 후 비용 6에서 10으로 우회했다. 도시는 주 중계기를 잃어도 예비 경로를 찾았다. 완전 단절에서는 목적지에 도달할 수 없었고 전체 장비 6대 중 3대에 도달했다. [개발노트 3](DEVELOPMENT_NOTE_03.md)

## 실행 화면과 영상

- [학생 삽입] 학교 회선 장애 전후의 경로와 비용 비교 화면
- [학생 삽입] BFS 큐 또는 다익스트라 거리 배열의 단계 화면
- [학생 삽입] 시나리오 선택 → 장애 발생 → 대체 경로 → Undo를 보여 주는 시연 영상
