# 설계

C17 엔진은 장비 배열과 양방향 인접 리스트를 관리한다. 웹은 정점의 화면 좌표, 이름, 아이콘과 재생 위치를 관리한다. 엔진의 정점 번호가 두 영역을 연결한다.

CLI와 WebAssembly는 같은 탐색 함수를 호출한다. 탐색 결과에는 경로, 비용, 도달 가능한 정점 수와 정점 처리 단계별 배열이 들어간다. 웹은 이 기록을 읽어 표시한다.

장애는 장비와 회선의 활성 상태만 바꾼다. 장비나 회선 삭제는 장애 이력을 초기화한다. 삭제한 항목을 되살리거나 다른 항목에 과거 장애 상태를 적용하는 일을 막기 위한 설계다.
