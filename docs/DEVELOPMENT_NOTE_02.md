# 2차시 개발노트 · 구현과 연동

1. `8cc53da`에서 C17 엔진, CLI와 자동 테스트를 구현했다. `add_edge`는 양 끝 목록에 넣을 항목을 모두 할당하고 나서 양쪽을 연결한다.
2. `search`는 BFS일 때 큐로, 다익스트라일 때 거리 배열에서 최솟값을 찾아 다음 정점을 고른다. 정점 하나를 처리할 때마다 현재 배열을 복사한다.
3. `9fa998a`에서 Emscripten으로 모듈을 빌드하고 React가 결과를 읽도록 했다. C의 엔진 상태를 읽어 SVG로 회선과 장비를 그린다. 이름과 좌표는 화면에 필요한 정보로, React가 관리한다.
4. 클라우드에 `emcc`가 없어서 서명된 Debian 패키지 인덱스를 사용해 임시 도구를 준비했다. 압축을 풀어 사용한 배포 패키지에서 LLVM 도구 이름 및 실행 경로가 기본 설정과 달라 실제 도구 위치를 지정한 뒤 WebAssembly 빌드를 완료했다.
